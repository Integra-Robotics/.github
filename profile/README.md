# Integra Robotics

Official GitHub organization of **Integra Robotics**.

This organization contains our repositories for robotics development, integrations, experiments, internal tooling, and customer projects.

## AgiBot X2 Ultra

For our **AgiBot X2 Ultra** platform, we currently use:

- **AimDK**
- **Firmware:** v1.0.10
- **Grippers:** OmniPicker

### Robot computers

- **PC1** — Motion control
- **PC2** — Development PC / Jetson NX
- **PC3** — Interaction module

Some repositories also contain copies of low-level configuration files and system resources from **PC1**, kept as reference for development and AI coding agents.
